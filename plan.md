# Red Hat Sponsorship Plan
## Focus: Open Source Software for Rocket Monitoring

---

## 1. Objective

Secure Red Hat support (technical, mentorship, infrastructure, and potential funding) by positioning the project as:

> An open-source, real-time telemetry and monitoring platform for edge environments

---

## 2. Strategic Positioning

### Core Idea
Do NOT present this as a “rocket project”.

Present it as:
- Distributed systems engineering
- Observability platform
- Edge computing use case
- Open-source contribution

---

### Alignment with Red Hat

| Project Component | Red Hat Relevance |
|------------------|------------------|
| Telemetry pipeline | Observability (Prometheus, Grafana) |
| Ground station | Edge computing |
| Deployment | OpenShift / Kubernetes |
| Open-source repo | Community engagement |
| CI/CD | DevOps ecosystem |

---

## 3. Open Source Strategy

### Goals
- Build credibility
- Attract contributors
- Align with Red Hat values

### Actions

#### Repository Setup
- Public GitHub repository
- Structure:
  - /backend
  - /frontend
  - /docs
  - /deploy
- Add:
  - LICENSE (Apache 2.0 or GPL)
  - CONTRIBUTING.md
  - CODE_OF_CONDUCT.md

---

#### Documentation
- Clear README:
  - Problem
  - Architecture
  - Setup instructions
- Architecture diagrams
- API documentation

---

#### Community Building
- Enable Issues + Discussions
- Tag beginner-friendly issues
- Accept external contributions
- Weekly updates

---

#### Open Source Improvements Focus
- Scalability
- Reliability
- Containerisation
- Observability
- Security

Examples:
- Kubernetes configs
- Helm charts
- Logging + metrics
- Fault tolerance

---

## 4. Technical Stack

- Backend: Go / Python
- Frontend: React

- Messaging: MQTT / Kafka
- Deployment:
  - Docker
  - Kubernetes

## 7. Sponsorship Pitch

### Problem
Real-time telemetry in constrained environments is complex.

### Solution
Open-source monitoring platform.

### Why Red Hat
- Open-source alignment
- OpenShift compatibility

### What You Offer

- Student engagement
- Visibility

### What You Ask
- Mentorship
- Infrastructure
- Optional funding
