# GUI Quickstart

1. Install Qt 6 (Core, Gui, Widgets, Charts modules) and CMake 3.21+.
2. From the repository root run:

   ``` bash
   cmake -S . -B build
   cmake --build build
   ```

3. Launch the demo window:

   ``` bash
   ./build/cosmo-soft
   ```

4. Remove build:

   ``` bash
   rm -rf build
   ```
